## 已实现

- 从每个种子的真实 ZERO-6 有限回放最终 checkpoint 恢复原 403 参数主体；随机初始化对照使用同结构主体。新增 1003 参数神经符号头，合计 1406 参数。旧任务预测器不因扩展而改变。
- 每个世界随机产生三种对象关系（属性、形态、动作），每种关系有三类结果；九个既有符号与关系值的映射随机排列，三个陌生符号在后段通过反馈学习。模型只收到对象特征、符号 ID 和合法反馈；词形只是 ID 的表面形式，不含答案。
- 神经前向包含“符号+对象→是否匹配”二类判断、根据匹配概率选择对象，以及“对象+关系提示→完整既有符号 ID”九类输出。后一输出是封闭词表的完整符号选择，不等同自由语言生成。
- 对照：实际随机预测、冻结继承模型、随机初始化学习、继承学习、继承加有限旧经验回放。三组训练臂配对新符号头初始化、世界和反馈顺序。
- 开发与封存对象独立；旧 ZERO-6 五项技能在扩展前、适应过程中和终点复测。查询对象与训练对象不重合，可检查未见对象组合。
