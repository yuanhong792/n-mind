# F0 数学规范（净室，独立于 Caishen 实现）

本规范在运行任何净室实验**之前**冻结。净室代码不 import `experiments/fly/fly_core.py`，按本规范独立实现。验收判据沿用 Caishen 预注册（P=10/50 召回须 1.0），**不得为了通过而调整**。

## 1. 编码（镜像 Caishen 预注册 §2.1–2.2 的构造，独立实现）

- 字符表 `NAME_CHARS = "小明红号位置哪里收到好了白了"`（13 唯一字符，按位置取 15 槽）。
- 名字 = 4 个随机字符。多热输入 `h ∈ {0,1}^690`：4 个 unigram 槽 + 3 个位置相关 bigram 槽（`15 + pos*225 + c1*15 + c2`），共 7 个 1（重复字符会合并，实际 ≤7）。
- 扩展层四种（单变量对照）：
  1. `frozen`：`R ∈ {0,1}^{M×D}`，每行恰好 `fan_in` 个 1（`rng.choice` 无放回），`z = R h`，全局 TopK `k = max(1, round(s·M))`，**并列按索引升序**（与 Caishen 预注册 §2.2 一致）。
  2. `signed`：同上但 `R ∈ {±1}`（唯一改动：R 的符号），用于隔离"平局退化"假设。
  3. `random_sparse`：支撑从 M 中均匀无放回抽 k 个（独立随机码，理论重叠 k²/M）。
  4. `dense_pm1`：稠密 ±1 码（期望正交）。
- 默认测量配置：`M=512, s=0.02 (k=10), fan_in=6, seed=20271301`（与 Caishen 自检一致）；容量实验另测 `M=2048, s=0.05 (k=102)`。

## 2. 记忆（Caishen 预注册 §2.3–2.4 变体 A）

`W ∈ R^{M×M}` 初始 0。写入 `(a,b)`：

```
若 decay != 1: W ← decay·W
δ = b − Wᵀa            （= b − aW）
W ← W + η·a δᵀ          （归一化臂：W ← W + g·a δᵀ/(‖a‖²+ε)，g=1，ε=1e-6）
W ← clip(W, −clip, +clip)
```

读出 `score(v) = a_qᵀ W φ(v)`，argmax（并列取候选索引升序）。

## 3. 实验（单变量，逐个隔离）

| 编号 | 目的 | 网格 |
|---|---|---|
| E1 | 编码冲突率 | 4 种编码 × 2000 随机名字对：支撑重叠 |∩|/k、余弦、理论 k²/M |
| E2 | 容量与 epoch 数 | 编码 {frozen,signed,random_sparse} × η {0.05,0.2,0.8} × P {10,50} × epochs {1,5,20,50} × 3 种子 |
| E3 | 更新干扰 | 重叠 ρ {0,0.3,0.6,0.9}：实测 Δread 与公式 η(a₁ᵀa₂)δ₂（及归一化臂）逐元素比对 |

| E5 | clip 消融 | 固定其余：clip {0.05,0.1,0.5,1.0,4.0,1e9} × P=10 |
| E6 | 数值稳定性 | M=256,k=5,η=0.2,5×10⁴ 写入；‖W‖_F 每 5k 记录；plain vs normalized；实测 CPU 秒 |
| E7 | 资源基准 | M=2048/512：稠密读 vs 稀疏 gather 读 1000 次墙钟、MAC、修正提案估算器 |

## 4. 验收与纪律

- 净室自检：P=1 时四种编码 × 两种公式召回必须 =1.0，否则判定**净室实现**错误并停止。
- 不改 Caishen 判据、不换种子、不删失败样本。
- 若 E2 显示 `frozen` 编码在 η=0.05 下即使 epoch 充足也无法达到 1.0，而 `signed` 可达，则根因为**编码平局退化**（设计层），不得以修改实现来掩盖。
- 若 E4/E5 显示 decay/clip 是主因，则按 Caishen 预注册 §2.3 的 decay 定义（每写一次衰减）核对实现。
