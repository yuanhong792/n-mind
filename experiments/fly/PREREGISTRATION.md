## 1. 先行工作、新颖性与预期增量

### 1.1 等价或接近方法

| 方法 | 关系 | 来源 |
|---|---|---|
| FlyHash / 果蝇稀疏扩展哈希 | 本设计的输入扩展层直接取自该机制：随机稀疏二值投影到高维 Kenyon-like 层，再全局 winner-take-all 得到稀疏码。 | Dasgupta, Stevens & Navlakha, *A neural algorithm for a fundamental computing problem*, Science 358(6364):793–796, 2017. DOI `10.1126/science.aam9868`。 |
| 随机稀疏扩展 + WTA 的一般形式 | FlyHash 的抽象版本；本设计把 fan-in、扩展维度和稀疏度作为工程网格扫描，不声称生物最优。 | 同上；另见 Shen, Dasgupta & Navlakha, *Reducing Catastrophic Forgetting With Associative Learning: A Lesson From Fruit Flies*, Neural Computation 35(11):1797–1819, 2023. DOI `10.1162/neco_a_01615`。 |
| 误差调制局部规则 / delta 规则 / LMS | 变体 A 在随机稀疏特征上就是 delta/LMS：令 `φ(x)` 为稀疏码、`w` 为某输出单元权重、`y = wᵀφ(x)`、目标 `t`，则 `Δw = η φ(x)(t - y) = -(η/2)∇_w (t-y)²`。在随机特征上它是线性最小二乘的在线随机梯度，不是新的学习规则。 | Widrow & Hoff 的 LMS/Adaline 传统；本预注册明确写出等价关系，不把其包装成新机制。 |
| Delta-rule 快权重 / 线性注意力 | 本设计的可塑层与“用外积更新快权重”的线性注意力/DeltaNet 类方法同族；差别是本设计不通过梯度训练、不端到端反传，且更新作用在固定随机稀疏码上。 | Katharopoulos et al., *Transformers are RNNs: Fast Autoregressive Transformers with Linear Attention*, ICML 2020, arXiv `2006.16236`；Schlag, Irie & Schmidhuber, *Improving Transformers with Dynamically Controllable Forgetting Mechanisms*, NeurIPS 2021, arXiv `2102.06546`。 |
| 稀疏分布式记忆 | 都是高维稀疏地址上的联想存储；本设计使用固定随机码 + 局部三因素更新，不使用 Kanerva 的激活/恢复迭代语义。 | Kanerva, *Sparse Distributed Memory*, MIT Press, 1988。 |
| 现代 Hopfield 网络 | 都是模式存储与召回；现代 Hopfield 通常有能量函数与指数/多项式吸引子动力，本设计是一次写入 + 一次内积读出，不声称等价。 | Ramsauer et al., *Hopfield Networks is All You Need*, ICLR 2021, arXiv `2008.02217`。 |

### 1.2 FLY 的预期增量

预期增量仅限定为：**在没有梯度反传、没有端到端参数训练、没有预训练权重的前提下**，固定随机稀疏扩展 + 全局 k-WTA + 局部三因素可塑性能否在 MQAR 机制测试上实现键值绑定、在新名字上迁移，并在持续学习协议下减少遗忘。它不预期在绝对准确率上超过阶段 2.5/2.6 的 Transformer，也不把“手工记忆能解 MQAR”解释为“模型具备学习能力”。

### 1.3 无增量的判定

以下任一结果出现，即认为 FLY 相对既有方法没有显示增量：

1. FLY-02 在 N=2、4、8 的 heldout_seq 排名准确率 95% CI 下界未全部 ≥ 0.90；
2. FLY-02 的打乱标签或关闭可塑性负对照高于随机水平 + 0.05；
3. FLY-02 的跟随率不能随键值交换改变，或簇级 CI 覆盖 0；
4. FLY-03 的遗忘下降幅度不优于同参数稠密 SGD 无回放对照；
5. FLY-06 的实测写入/读取耗时不优于同维度稠密层或注意力实现；
6. 与 2.7 Delta-rule 基线并列时，FLY 的排名/跟随没有稳定优势；若该基线不可用，只能标 `待比较`，不得推断。

## 2. 模块定义

### 2.1 输入编码

- 字符表来自 MQAR 现有词表与 `NAME_CHARS = "小明红号位置哪里收到好了白了"`，不新增外部数据。
- 每个 4 字名字 `c0c1c2c3` 编码为多热向量：
  - 单字符特征：`uni(c0), uni(c1), uni(c2), uni(c3)`；
  - 相邻二元组特征：`bi(pos0,c0,c1), bi(pos1,c1,c2), bi(pos2,c2,c3)`。
- 维度固定为 `D = 15 + 3 × 15 × 15 = 690`；位置相关二元组避免 `ab/ba` 混淆。
- 编码不参与梯度，不使用 autograd。

### 2.2 稀疏扩展层（Kenyon-like）

- 固定随机稀疏矩阵 `R ∈ {0,1}^{M×D}`，每行恰好 `fan_in` 个 1，按固定种子无放回采样。
- 预激活 `z = R h`，其中 `h` 为 2.1 的多热输入。
- 全局竞争：全部 M 个单元一起排序，取最高 `k = max(1, round(s·M))` 个为 1，其余为 0；并列时按单元索引升序打破。
- 网格：`M ∈ {512, 2048, 8192}`；`fan_in ∈ {3, 6, 12}`；`s ∈ {0.01, 0.02, 0.05, 0.10, 0.20}`。
- 默认值仅用于单元测试与示例：`M=2048, fan_in=6, s=0.05`；不得根据结果改网格。

### 2.3 可塑层（输出神经元类比）

权重 `W ∈ R^{M×M}`，随机初始化为 0；每次写入前先做衰减 `W ← decay · W`，更新后逐元素裁剪到 `[-clip, clip]`。

记键稀疏码 `a = φ(key)`，值稀疏码 `b = φ(value)`。

- **变体 A：误差调制的势能化（delta 规则）**
  - 调制信号 `δ = b - Wᵀa`；
  - 更新 `W ← W + η · a δᵀ`；
  - 因为 `δ = -(1/2)∇_W ||b - Wᵀa||²`，所以这是随机稀疏特征上的 delta/LMS 等价形式。
- **变体 B：多巴胺式抑制（反赫布对照）**
  - 正确写入时调制信号 `d = +1`；
  - 当 `d > 0` 时，对活跃前突触行与活跃目标列抑制：`W ← W - η · d · a bᵀ`；
  - 当 `d ≤ 0` 时不更新；
  - 该变体按任务书要求报告，不预设它会有效。

网格写死：

- `η ∈ {0.05, 0.2, 0.8}`
- `decay ∈ {0.99, 1.0}`
- `clip ∈ {1.0, 4.0}`
- `variant ∈ {A, B}`

总配置数：`3 × 3 × 5 × 3 × 2 × 2 × 2 = 1080`。

### 2.4 读出

- 对查询键稀疏码 `a_q` 与候选值稀疏码 `φ(v)` 计算 `score(v) = a_qᵀ W φ(v)`。
- 取分数最大者；并列按候选索引升序。
- 候选集合与 MQAR 评测口径一致：每条样本的 N 个值候选。
- 不使用 softmax 训练，不使用梯度。

## 3. 实验与判据

### 3.1 FLY-00 记忆容量

- `P ∈ {10, 50, 100, 500, 1000, 5000}`。
- 每个 P 生成 P 个随机键值对，写入后逐条查询全部 P 个键，记录召回准确率。
- 低负载 `P=10` 与 `P=50` 的召回必须对所有配置、所有种子为 1.0；否则判定实现错误，停止全部后续实验。
- 对照：
  1. 稠密随机码联想记忆，参数量按 `M×M` 对齐；
  2. 线性注意力式外积记忆 `W += b aᵀ`，读出同 2.4。
- 预期随 P 增大容量下降；不预期无限容量。

### 3.2 FLY-01 干扰

- 键之间受控相似度：编辑距离 1、2、3，每档 100 组。
- 记录召回准确率与键稀疏码 Jaccard 重叠度。
- 对照：同维度无 k-WTA 的稠密随机投影。
- 若捷径/随机基线高于随机水平 + 0.05，停止并报告。

### 3.3 FLY-02 上下文绑定

- 数据：沿用 `experiments/phase2_baselines/mqar_task.py` 的哈希校验入口。
- `N ∈ {2, 4, 8, 16}`；`split ∈ {heldout_seq, heldout_name}`。
- 封存集：
  - N=2、N=4 使用现有 `heldout_seq_seal2`（哈希分别在 `mqar_N2_heldout_seq_seal2.meta.json`、`mqar_N4_heldout_seq_seal2.meta.json`）；
  - N=8、N=16 生成同类型 seal2-like 封存集，固定生成种子分别为 `20271208`、`20271210`，排除 train/dev/test 指纹，写入 `experiments/fly/data/seal2_like/` 并记录 SHA-256；
  - 每个配置只读封存集一次，记录读取哈希。
- 每个 N/split 每种子取固定 200 条封存序列（按序列索引 `0..199`，固定不重抽）。
- 每条序列开始时重置记忆；序列内写入全部键值对，再回答查询。
- 指标：
  - 主指标：候选排名准确率；
  - 跟随率：交换键值对后答案是否跟着变；
  - 簇级 bootstrap 95% CI，簇 = 序列，簇数 = 200；
  - 捷径基线：只用查询键位置/最后值/频率等非绑定线索；
  - 负对照：打乱标签、关闭可塑性。
- 正控制：阶段 2.5/2.6 Transformer 结果；Delta-rule 基线：阶段 2.7 结果可用时并列报告。
- 明确声明：这是机制测试，不含参数训练；一个手工记忆能解 MQAR 不能说明它具备学习能力。

### 3.4 FLY-03 保留与遗忘

- 任务 A：一批名字关联；任务 B：不同名字池的新一批关联；学习 B 时记忆不重置。
- 存储条目数 ∈ `{10, 100, 500}`。
- 指标：A 的召回下降量、B 的学习程度。
- 对照：
  1. 同参数量稠密小网络，SGD，1 线程，总计 ≤ 5 分钟；
  2. 同稠密网络 + 回放版本。
- 若稠密对照在该协议下没有出现遗忘，如实写“该协议无区分力”，不得强行解释。

### 3.5 FLY-06 开销

- 每次写入与读取的 CPU 实测耗时：1 线程，预热后取中位数，重复 ≥ 5 次。
- 同时给出操作数估算，但结论只使用实测耗时。
- 对比稠密层与注意力实现；只报告实测，不用理论节省替代。

## 5. 预算与耗时估算（写死，运行前判定）

总预算：CPU only，1 线程/进程，并行 ≤ 8，FLY-00 至 FLY-03 与 FLY-06 合计墙钟 ≤ 60 分钟。

配置数 1080，种子数 10，故每个实验的基础运行数为 10800。

保守估算依据：

- 网格平均 `M≈3584`、平均 `s≈0.076`，平均 k-WTA 活跃单元约 272；
- 单次外积更新约 `272² ≈ 7.4e4` 个浮点写入；
- FLY-00 每运行写入/读取 `P` 总和 6660 条，平均约 `4.9e8` 浮点写入；
- FLY-02 每运行约 200 序列 × 平均 7.5 写入 = 1500 次写入，平均约 `1.1e8` 浮点写入；
- FLY-03 每运行约 600 次写入，平均约 `4.4e7` 浮点写入；
- 再计 FLY-01、控制组、CI、哈希校验与进程开销。

合计量级约 `7e12` 浮点写入，折合单线程内存流量约 56 TB；按 1–5 GB/s 估计需 **3.1–15.6 小时**，明显超过 60 分钟预算。

**因此本预注册在预算判定上写死：`D_STAGE_STATUS = STOP_BUDGET_ESTIMATE`。**
按任务书“估算超限则停止并报告，不自行缩小规模”，本轮不启动 FLY-00/01/02/03/06 的正式运行；不缩小网格、不减种子、不改判据。若要运行，需要另行批准扩大预算，或另写新预注册缩减网格（后者属于新实验，不得冒用本预注册）。
