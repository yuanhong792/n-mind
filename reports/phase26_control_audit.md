## A. 排名指标审计（不训练，只用 dev 集）

### A.0 触发原因

[phase25](phase25_mqar.md) N=2 seed101 自由生成 EM 0.991 vs 候选排名 0.766：N=2 只有两个候选，若贪心每步都选中正确值，正确候选的序列对数概率应几乎总是更高。审计确认：**数学直觉正确，排名实现有 bug**。

### A.1 逐样本证据（N=2 seed101，dev 1000 条，封存集未用于调试）

| 指标 | 数值 |
|---|---|
| 贪心 EM | 0.986 |
| 排名（buggy，修复前） | 0.762 |
| 排名（修复后） | **1.000** |
| 贪心对 但 buggy 排名错 | **233/1000（23.3%）** |
| 贪心对 但修复后排名错 | **0/1000** |
| 贪心错 但 buggy 排名对 | 9 |
| 贪心错 但修复后排名对 | 14 |

20 个"贪心对但 buggy 排名错"的样本（`_diag_rank.py` 输出，代表性 5 例）：

**i=2** query=收了红位 true=白了位到 gen=白了位到
- 正确候选逐 token logp（真上下文）= [-0.000, -0.009, -0.000, -0.000]，sum = **-0.009**
- 错误候选 = [-9.932, -8.883, -13.740, -13.042]，sum = **-45.597**
- buggy 分：正确 -32.54 vs 错误 -29.27 → **判错**；修复后：-0.009 vs -45.60 → 判对
- 无结束符/分隔符混入；候选均为 4 字值；无平局

**i=4** true=小白号红：正确 sum -0.025 vs 错误 -35.52；buggy 判错，修复后判对
**i=9** true=位好号里：错误候选第 2 字与正确相同（共享前缀断裂），buggy 仍判错
**i=17** true=白收红了：正确 sum -3.09 vs 错误 -15.99，差距最小的一例，修复后仍判对

其余 15 例同模式（完整清单见 `_diag_rank.py` 运行日志；占比 23.3%）。所有例中修复后得分都把正确候选排第一；平局 0 例。

### A.2 实现检查清单

| 项 | 结论 |
|---|---|
| 候选集合含正确值、去重、与上下文值一致 | 1000/1000 |
| 候选分词 == 实际答案切片 | 1000/1000 |
| 平局处理 | argmax 取首索引；修复后 dev 上 0 平局 |

### A.3 单元测试（修复前必须暴露）

[test_mqar_eval_sanity.py](../tests/test_mqar_eval_sanity.py)：

- **a) 手写 scorer**：位置 3 放决定性证据，buggy gather（候选 0 只用位置 0）判错——修复前 `AttributeError: candidate_scores` / 判错，修复后过。
- **b) 完美复制模型**：EM=1、follow=1，**修复前 rank=0.865（≠1）**，修复后 rank=1.0。
- **c) 一致性不变量**：真 checkpoint 贪心对 ⇒ 排名对。修复前违反 72/300（24%），修复后 ≤3/300（实测 0）。
- **d) 打乱标签负对照**：排名 ≈ 0.5（过）。

### A.4 结论（二选一）

**排名实现有 bug。** 机制：`rank_eval` 用 `seg.gather(2, cand).sum(-1)`，torch `gather(dim=2)` 语义是 `out[b,j,t] = seg[b, j, cand[b,j,t]]`——**候选序号 j 被当成答案槽位**。N=2 时候选 0 的 4 个 token 全部在位置 0 打分、候选 1 全部在位置 1 打分，比较的是不同位置、不同 token 的无意义混合。修复为 `candidate_scores`：`sc[b,j] = Σ_t lp[b, plen-1+t, cand[b,j,t]]`。

修复提交 **`54af4dc`**（只改 `rank_eval`/新增 `candidate_scores`/`cluster_bootstrap_ci` + 测试），**早于**本报告任何新门槛数字。历史 JSON 未改写。

**排名是否合适作门槛指标（只报告，未改门槛）**：修复后排名衡量"正确值在 N 个候选中序列概率最高"，是预注册指标且实现正确。它与自由生成 EM 仍会分离（seal2 上 s102 N=2 排名 0.989 / EM 0.474）——序列概率偏好正确值不等于贪心解码走出正确串（曝光偏差/多峰）。排名门槛比 EM 宽松，但定义明确、可复现、已被预注册；EM 作为次要指标一并报告。
